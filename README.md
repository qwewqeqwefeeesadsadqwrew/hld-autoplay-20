# 快乐小日子 · 自动玩（网页版 · 20 关）

打开网址就能自动玩，不需要装任何东西，手机上也能用。

**已解锁全部 20 关**：原来的 10 关 + 新增 10 关（意面、寿司卷、冰淇淋、咖喱、
蜗牛、三文鱼、惠灵顿牛排、蛋挞、可乐鸡翅、马卡龙塔）。
每轮随机洗牌，20 关打完自动开下一轮，无限循环；操作节奏按真人模拟，带随机停顿。

## 这个仓库里有什么

只有三个自己的文件：

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面外壳，负责按顺序加载脚本 |
| `hook.js` | 补丁壳：在官方脚本执行前就地改写（见下） |
| `autoplay.js` | 自动玩逻辑：20 关随机顺序、无限循环、模拟真人节奏 |

游戏素材和官方脚本**不在仓库里**，全部从官方 CDN
（`static.zuiqiangyingyu.net`）实时拉取，所以仓库体积只有 110KB 左右。

## 为什么要 hook

官方脚本里有三道锁，在非官方域名下会拒绝运行：

1. **域名锁** —— 13 个包脚本 + 启动脚本里各有一处
   `if(!_0xXXXX){var _0xYYYY=new RegExp('...`，不改就会跳到 `about:blank`。
2. **引擎解密钥匙** —— `SASE.decrypt(n, location.hostname)`，
   config 是拿官方域名当密钥加密的，要写死成官方域名。
3. **反调试守卫** —— 启动脚本里的 FuckDevtool，手机地址栏伸缩会误判。

`hook.js` 在脚本真正执行前把它们抓下来、在内存里改好，再用 blob 挂上去。
改好的脚本存进 CacheStorage，第二次打开不用重算。

## 注意

- 第一次打开要从官方 CDN 下载约 57MB 脚本（和玩官方原版一样），会比较慢；之后走缓存。
- 网址谁拿到谁能打开。
